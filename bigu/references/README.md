| 文件 | 说明 |

## 规则

1. 新增或修改原子，必须同步 `knowledge-atoms.jsonl` 与 `knowledge-atoms.md`。
2. 新增公开文献来源，必须先在 `证据与出处.md` 登记书目与冲突口径。
3. 出现疗效类表述一律剔除，不做「温和化改写」保留。
