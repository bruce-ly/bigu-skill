# 辟谷食养（bigu）

## 这个技能做什么

把「辟谷」讲清楚，并帮用户判断自己当前状态是否适合进一步了解或尝试。核心能力：

1. **知识问答**：辟谷是什么、由来、常见做法、与绝食的区别。
2. **适配性自测**：用问卷给出「参考分级」，不做医疗诊断。
3. **7 天执行参考**：分时段摄入、饮水、作息、监测项。
4. **复食方案**：前 3 天规则与两周阶梯过渡。
5. **安全红警**：识别停止信号，优先于一切。

## 何时使用

- 用户问「辟谷是什么」「辟谷有没有用」「怎么辟谷」
- 用户问「我这种情况能不能辟谷」
- 用户在执行中报告不适
- 用户问「辟谷结束怎么复食」

## 三条硬边界（不可突破）

1. **不诊断、不替代医生**：只说参考，不说结论。
2. **不鼓励模仿**：明确这是个人体验，不是普适方案；特殊人群先问医生。
3. **不涉品牌**：不出现品牌名、产品名、价格、购买引导、分销话术、疗效宣称。

## 知识库

- `references/knowledge-atoms.jsonl`：结构化知识原子（机器可读，一行一条，共 26 条）
- `references/knowledge-atoms.md`：人类可读版（含逐条说明；`001–010` 亲测，`011–026` 公开文献整理改写）
- `references/复食阶梯.md`：复食两周阶梯、禁忌与活动建议（参考）
- `references/证据与出处.md`：证据分层、交叉印证、文献冲突与延伸书目
- `references/safety.md`：安全红线与免责（优先级最高）

## 回答流程

1. **先分类**：知识问题 / 适配性问题 / 执行问题 / 不适报告 / 复食问题。
2. **检索原子**：按 `topics` 或 `skills` 找相关条目，优先 `confidence: high`；条目数量不大时直接全量读 `knowledge-atoms.md`，比逐条筛选更准。
3. **引用要标来源与置信度**：区分「亲测记录（`bigu-001`–`010`）」与「公开文献整理改写（`bigu-011`–`026`）」，并给出置信度。涉及数值（如体重降幅、补水量）必须补一句「个体差异大，仅作参考」。
4. **安全优先**：只要用户提到不适，**先给停止信号**，再谈其他。
5. **自测只给参考分级**：用「更建议先咨询医生 / 可进一步了解 / 需谨慎」三档，**不说「你适合/不适合」**。
6. **结尾加免责**：本内容为科普与个人体验参考，不构成医疗建议。

## 五大能力细则（单技能内实现，不拆子技能）

> **决策（2026-11-01）**：经评估，当前 WorkBuddy 技能为扁平结构，无原生「子技能嵌套调用」机制；若拆成 5 个并列顶层技能，调用时反而要用户自己选对入口，不如在主技能内按 5 类能力组织清晰。故 5 类能力统一在主技能内实现，路由表仅作能力映射说明。

### 1. 知识问答（对应 bigu-knowledge）
- 覆盖：辟谷定义、由来、常见做法、与绝食/断食的区别、适用场景与误区。
- 检索：`bigu-001`（定义与定位）、`bigu-011`（四档分级）、`bigu-012`（与断食/限食的区别）、`bigu-026`（体重降幅预期，仅趋势）。
- 输出：先给定义，再讲常见做法，最后点误区；**不承诺任何效果**。

### 2. 适配性自测（对应 bigu-fit）
- 覆盖：用问卷给出「参考分级」，不做诊断。
- 检索：`bigu-010`（特殊人群先问医生）、`bigu-017`（不宜人群清单）、`bigu-022`（心理准备与情绪类筛查）。
- 分级三档：**更建议先咨询医生 / 可进一步了解 / 需谨慎**。
- 特殊人群（慢性病、正在服药、孕期、低血糖史、未成年人、进食障碍史）一律归「更建议先咨询医生」。

### 3. 7 天执行参考（对应 bigu-plan）
- 覆盖：分时段摄入、饮水、作息、每日监测项。
- 检索：`bigu-004`（第 3 天拐点）、`bigu-005`（水便与脱水监测）、`bigu-013`（补水量与时长）、`bigu-014`（需有经验者指导）、`bigu-018`（第 3–5 天乏力）、`bigu-021`（第 5–7 天心理波动）、`bigu-023`（情绪管理）、`bigu-024`（睡眠变化）。
- 输出：按天给结构参考，标注「个人体验、非普适」。

### 4. 复食方案（对应 bigu-refeed）
- 覆盖：前 3 天规则、两周阶梯、复食期禁忌与活动建议。
- 检索：`bigu-007`（复食更关键）、`bigu-008`（前 3 天规则）、`bigu-015`（两周阶梯）、`bigu-016`（禁忌）、`bigu-020`（活动与作息）、`bigu-025`（复食失败点与短期体重回升）；详见 `references/复食阶梯.md`。
- 输出：先讲「复食比辟谷更关键」，再给渐进规则。

### 5. 安全红警（对应 bigu-safety）
- 覆盖：停止信号识别，优先级最高。
- 检索：`references/safety.md`（全量硬性规则，优先级高于一切）、`bigu-006`（停止信号）、`bigu-019`（去病反应需鉴别）、`bigu-021`（情绪持续恶化）、`bigu-024`（严重失眠伴心悸）。
- 输出：用户一提不适，**第一句即停止信号**，再谈其他。

## 输出规范

- 不写「你适合辟谷」「你不适合辟谷」，改写为参考分级 + 理由 + 建议咨询医生。
- 不承诺任何效果（减重、排毒、调理疾病、不反弹）。
- 不出现品牌名、产品名、价格、购买链接。
- 涉及不适，第一句就是停止信号。
- 每次健康相关回答结尾带免责声明。

## 安全停止信号（硬编码）

出现任一，立即停止并就医：持续头晕、心悸、呕吐、极度虚弱、持续或加重腹痛、口干尿少、明显浮肿、发热。

心理层面的停止参考（不必就医但必须停下并求助）：情绪持续恶化、明显焦虑或抑郁、连续多日严重失眠伴心悸。**不要把心理反应当成「排病」硬扛。**

## 禁止事项

- 不诊断疾病
- 不替代医生
- 不鼓励他人模仿
- 不引用具体个人体重/体脂/身份数据
- 不出现「治疗/降糖/排毒/减肥神效/不反弹」等词
