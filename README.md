# 辟谷食养 · bigu skill

面向 Agent Skills 开放标准的**辟谷科普与适配性自测**技能。

给用户问「辟谷是什么」「我这种情况能不能辟谷」「辟谷结束怎么复食」时一个有边界、有来源、有置信度的回答，而不是泛泛的养生鸡汤。

## 特性

- **26 条知识原子**：`001–010` 来自个人亲测实录（已脱敏），`011–026` 来自公开文献要点改写（不转载原文）。
- **证据可溯源**：`references/证据与出处.md` 记录证据分层、交叉印证、文献冲突与延伸书目。
- **安全优先**：硬编码停止信号（持续头晕、心悸、呕吐、极度虚弱、腹痛、口干尿少、浮肿、发热），心理层面另有停止参考。
- **三档参考分级**：只给「更建议先咨询医生 / 可进一步了解 / 需谨慎」，**不说「你适合/不适合」**。
- **双形态**：技能包 + 面向普通受众的《大众版手册》。

## 安装

把 `bigu/` 目录复制到目标工具的 skills 目录：

```bash
# WorkBuddy
cp -R bigu ~/.workbuddy/skills/bigu
# Claude Code
cp -R bigu ~/.claude/skills/bigu
# 通用约定
cp -R bigu ~/.agents/skills/bigu
```

## 五大能力

| 能力 | 做什么 |
|---|---|
| 知识问答 | 定义、由来、常见做法、与绝食/断食的区别、误区 |
| 适配性自测 | 问卷 + 三档参考分级，不做诊断 |
| 7 天执行参考 | 分时段摄入、饮水、作息、监测项 |
| 复食方案 | 两周阶梯、禁忌、活动与作息 |
| 安全红警 | 停止信号识别，优先级最高 |

## 边界（重要）

- **不诊断、不替代医生**：全部内容为科普与个人体验参考，不构成医疗建议。
- **不鼓励模仿**：单样本经验不能推广为普适方案；慢性病、服药、孕产期、术后、未成年人等请先咨询医生。
- **不宣称疗效**：不含「治疗 / 降糖 / 排毒 / 减肥神效 / 不反弹」等表述。
- **不涉品牌**：无品牌名、产品名、价格、购买引导。
